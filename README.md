# BrewHub - Professional Web3.0 Coffee Shop Website

## 🚀 Overview

BrewHub is a modern, professional coffee shop website built with Next.js, React, Three.js, and Framer Motion. It features stunning Web3.0 animations, 3D effects, and blockchain integration.

## ✨ Features

### 🎨 Advanced Animations
- Floating animated background orbs
- Particle system with smooth transitions
- Neon glow text effects
- Smooth scroll animations
- Hover lift & scale effects
- Staggered card reveals
- Number counter animations

### 🌐 Web3.0 Integration
- **BREW Token System** - Earn tokens on purchases
- **NFT Rewards** - Exclusive membership cards
- **DAO Governance** - Vote on menu items
- **Staking Rewards** - Passive income generation
- **Blockchain Ready** - Smart contract support

### 3️⃣ 3D Features
- Interactive 3D coffee bean scene
- Rotating torus ring with glow effects
- Orbit controls for user interaction
- Realistic lighting & materials
- Smooth animations

### 📱 Responsive Design
- Mobile-first approach
- Hamburger navigation menu
- Touch-friendly interactions
- Optimized for all screen sizes
- Accessibility ready

### 🎯 Modern UI/UX
- Glassmorphism design
- Custom gradient text
- Smooth color transitions
- Professional typography
- Intuitive navigation

## 🛠️ Tech Stack

- **Frontend Framework**: Next.js 14
- **UI Library**: React 18
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion + GSAP
- **3D Graphics**: Three.js + React Three Fiber
- **Web3**: Web3.js + Ethers.js
- **Language**: TypeScript

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/Ahm3d-2005/coffee-shop-website.git

# Navigate to project
cd coffee-shop-website

# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

## 📂 Project Structure

```
src/
├── components/
│   ├── Animations.tsx       # Reusable animation components
│   ├── CoffeeScene.tsx      # 3D Three.js scene
│   ├── Navigation.tsx       # Header navigation
│   ├── Sections.tsx         # Hero, Features, Stats, CTA
│   └── MenuGallery.tsx      # Menu, Gallery, Web3, Footer
├── pages/
│   ├── _app.tsx            # App wrapper
│   ├── _document.tsx       # Document wrapper
│   └── index.tsx           # Main page
├── styles/
│   └── globals.css         # Global styles & animations
└── public/                 # Static assets

```
